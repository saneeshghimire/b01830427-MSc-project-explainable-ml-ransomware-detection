## A Comparative Study of Explainable Machine Learning Models for Ransomware Attack Detection

**Student:** Saneesh Ghimire (B01830427)  
**Programme:** MSc Cybersecurity  
**University:** University of the West of Scotland  

### Dataset
CIC-MalMem-2022 (58,596 samples, 55 features)

### Models
- Decision Tree (White-Box)
- Explainable Boosting Machine (Glass-Box)
- Random Forest (Ensemble)
- XGBoost (Ensemble)
- Logistic Regression (Linear Baseline)

### XAI Methods
- SHAP (SHapley Additive exPlanations)
- LIME (Local Interpretable Model-agnostic Explanations)
- Intrinsic Feature Importance
